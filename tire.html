📘 【前編】Tier表専用コード（データ構造）

tierList / tiers
【意味】SからGまでの各行（Tier）をまとめる最外殻の配列。
tierName / label
【意味】各行の左端に表示する「S」「A」「B」などの文字列データ。
tierColor / bgColor
【意味】Sは赤、Aはオレンジ、Bは黄など、各行の背景色を指定するデータ。
items / characterList
【意味】そのTier（行）の中に今どの画像（キャラクター）が並んでいるかを管理する配列。
Tier表単語帳 - 中編

🇨🇳 【中編】開発でよく使われる汎用コード①（ドラッグ＆ドロップ）

onDragStart
【意味】画像をマウスで掴んで動かし始めた瞬間に発動する処理。
onDrop
【意味】掴んだ画像を別のTierに移動（パッと離した瞬間）させる処理。
React Beautiful DND
【意味】ドラッグ＆ドロップの動きを実装するためによく使われる汎用ライブラリの1つ。
SortableJS
【意味】要素の並び替えを実装するためによく使われる汎用ライブラリの1つ。
Tier表単語帳 - 後編

📙 【後編】開発でよく使われる汎用コード②（画像ダウンロード）

html2canvas
【意味】完成したTier表を1枚の画像として保存する際によく使われる外部ライブラリ。
canvas.getContext
【意味】Webサイトのスクリーンショット機能などで広く使われている、画像を生成するためのブラウザ標準機能。
Tier表単語帳 - 後編2

👑 【後編2】開発でよく使われる汎用コード③（レイアウト）

flex (Flexbox)
【意味】S、A、Bの行を綺麗に横並び・縦並びにするためのCSS（デザイン用のコード）。
grid (CSS Grid)
【意味】要素を格子状（グリッド）に綺麗に整列させるためのCSS（デザイン用のコード）。
