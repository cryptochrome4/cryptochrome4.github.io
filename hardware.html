機密 LEVEL-2

📋 前提任務

Steamゲーム（中～軽量）／ バイブコーディング（Vibe Coding）／ Bitflyer・SBI証券 のブラウザ投資 ／ 自作サイト（HTML/CSS/JS）で勉強 ／ 予算は最小限 ／ デザインはミリタリー風（見た目はどうでもいいが、このページはその雰囲気）

🔧 最低限の必要スペック

✅ これだけ満たせばOK

  • CPU : Intel Core i3 (12世代以降) / AMD Ryzen 3 (5000番台以降) または 同等
  • RAM : 16GB (8GBはギリギリ、投資サイト+ゲーム+コードで足りなくなる)
  • ストレージ : SSD 512GB (256GBはすぐ埋まる。ゲームと開発で)
  • GPU : 内蔵GPU (Iris Xe / Radeon) で十分。Steamの軽めのゲームなら動く
  • 画面 : 13～15.6インチ、フルHD (1920x1080) 以上
  • その他 : USBポート複数、HDMI、Wi-Fi 6

目安 6～9万円 (新品・型落ち)

⚠️ 情弱が飛びつく「いらない機能」

  • 4K有機ELディスプレイ → 投資とコーディングにはオーバースペック。バッテリー食う、高い
  • RTX 4070以上のGPU → 重いゲームしないなら無駄。バイブコーディングに不要
  • 32GB RAM → 16GBで足りる。将来用と言いつつ大半は使わない
  • 2TB SSD → クラウドと外付けで十分。価格が跳ね上がる
  • 「AI専用NPU」 → 現状はほぼ宣伝用。投資にもコーディングにも関係なし
  • 「軍用規格MIL-STD-810H」 → タフだが重量増、価格高。ミリタリー風デザインなら別だが...
  • 「クリエイター向け」 → 色域100%など不要。投資サイトの色は正確じゃなくていい

🎯 情弱が騙される機能ランキング

順位機能・宣伝文句なぜ騙されるか実際の必要性
1「AI PC」「Copilot+ PC」流行語。なんとなく未来っぽい投資とコーディングには不要。ただのマーケティング
2「32GBメモリ搭載」数字が大きい＝偉いと思い込む16GBで十分。ゲーム+ブラウザ+コードでも足りる
3「4K有機EL」綺麗そう。でも小さい画面で4Kは無意味フルHDで十分。バッテリーも持つ
4「RTX 4060/4070」ゲームがサクサク？実際は重いゲーム向け内蔵GPUでSteamのインディー・軽めの3Dは動く
5「2TB SSD」容量大きい＝安心512GB＋外付けHDD/クラウドで十分
6「薄型軽量0.9kg」持ち運び？実際は家でしか使わない1.5kg前後でOK。剛性と価格のバランス重視
7「MIL-STD-810H準拠」軍用＝タフ＝ミリタリー風？通常使用で落とさないなら不要。重量増

🚫 買わない方がよいメーカー・シリーズ（情弱狩り）

❌ 避けるべき

  • 激安中華ブランド（無名） → サポート無し、発熱、すぐ壊れる
  • 「〇〇搭載！最新AI！」を前面に出す型落ち → 中身は旧型
  • メモリ8GBで「ゲーミング」 → 詐欺レベル。すぐ不足
  • HDD搭載モデル（2025年現在） → 遅すぎて投資サイトも重い
  • 「Office付き」で+3万円 → 無料のLibreOfficeで十分。Googleドキュメントでも
  • 「長期保証」を強制加入 → 不要。クレカの延長保証で事足りる

△ 注意が必要

  • Lenovo IdeaPad 一部 → 安いがプラスチックが弱い。予算最優先なら可
  • ASUS Vivobook 下位 → 8GBモデルが多い。16GBを選ぶこと
  • HP 15シリーズ → 型落ちで安いが画面が暗い。投資には支障なし
  • マウスコンピューター / パソコン工房 → 安いがサポートは期待するな

✅ 比較的安心（安め）

  • Lenovo ThinkPad E14 / L14 → 中古も含め頑丈。ミリタリー風デザイン多数
  • Dell Latitude 3000番台 → ビジネス向け、中古が狙い目
  • Apple MacBook Air M1 (中古) → 8GBでも軽い。ただしSBI証券の一部サイトは要確認
  • ASUS TUF Gaming F15 (型落ち) → ミリタリー風デザイン、RTX2050等で安い

🛒 情弱でも騙されない購入テクニック

💰 金を節約する技

  • 型落ちを狙え → 2023年モデルを2025年に買う。半額以下も
  • 中古（メルカリ、ヤフオク、じゃんぱら） → ビジネスノートは頑丈。バッテリーだけ注意
  • 公式アウトレット → Lenovo、Dell、HPの整備済み品は安い
  • 楽天スーパーセール、Amazonタイムセール → 急いでないなら待つ
  • メモリは後から増設できるか確認 → 8GBモデルを買って+8GBが最安のことも
  • SSDも換装可能か → 256GBを買って1TBに換装
  • 「Officeなし」を選ぶ → 不要ならその分安い
  • 学生・教員割引 → 該当するなら活用

🧠 騙されないための心得

  • 「AI」「Copilot」は無視 → 投資とコーディングに不要
  • 数字のマジックに注意 → 「最大〇〇時間駆動」はカタログ値
  • 「ゲーミング」の文字に踊らされない → 内蔵GPUでもゲームはできる
  • レビューは「星1」から読む → 騙されポイントが書いてある
  • 実店舗で触る → キーボード、画面、重さを確認
  • 「今だけ！」に急かされない → セールは毎月ある
  • 投資サイト（SBI証券）はブラウザベース → 特別なスペック不要
  • Bitflyerもブラウザで動く → 重いアプリは不要
