数学 × サッカー戦術分析

〜 微分を使って、最強のフォーメーション（最大体積）を導き出す 〜

📋 元の問題

縦 24cm、横 45cm の板がある。四隅を正方形に切り取り、残った部分で箱をつくれ。
この時、その体積を最大にするには、1辺が何cmの正方形を切り取ればよいか求めよ。
※板の厚みは考えなくて良い。

📐 数学としての正しい解法順序

ステップ 1: 切り取る長さ \(x\) の範囲（定義域）

・縦： 24 - 2x > 0 → x < 12
・横： 45 - 2x > 0 → x < 22.5
・長さ： x > 0
【定義域】 0 < x < 12

ステップ 2: 体積の式 \(V(x)\) の構築と展開

V(x) = x(24 - 2x)(45 - 2x)
V(x) = 4x³ - 138x² + 1080x

ステップ 3: 微分と因数分解

V'(x) = 12x² - 276x + 1080
V'(x) = 12(x² - 23x + 90)
V'(x) = 12(x - 5)(x - 18)

ステップ 4: 増減表による検証

x (0) ... 5 ... (12)
V'(x) + 0 -
V(x) ↗ 最大 ↘

定義域内（0 < x < 12）で最大となるのは x = 5 のとき。

【答え】 5 cm

⚽ サッカー戦術全体での例え

この問題の本質は、「限られたリソースの中で、一番攻撃力の高い（体積が最大になる）黄金の陣形を見つけ出す」という、監督の戦術設計そのものです。

📈 数学の概念
  • 定義域の決定: 板のサイズをはみ出して切り取ることはできない。
  • 体積の数式: 縦・横・高さを掛け合わせてボリュームを作る。
  • 微分で傾き調査: グラフの「上り坂・下り坂」の勢いを調べる。
  • 微分 = 0 の瞬間: 上り坂が終わり、頂点（マックス）に達した瞬間。
🏃‍♂️ サッカー戦術への翻訳
  • ピッチのルール: 選手はタッチライン（外線）を超えて動けない。
  • 戦術の方程式: 中央の厚みとサイドの幅の「バランス調整式」。
  • スカウティング: 「人数を増やすと攻撃力がどう変わるか」のデータ分析。
  • 最強の黄金比: 「これ以上バランスを崩すと大失敗する」という必勝陣形。
💻 計算ステップの戦術データ分析

数式の変形ひとつひとつにも、サッカーのデータ分析としての意味があります。

① 式の展開: V(x) = 4x³ - 138x² + 1080x

【作戦ボードの整理】 各ポジション（カッコ）にバラバラに書かれていた選手の特徴メモを綺麗にまとめ、チーム全体の「総攻撃力方程式」を一本のスッキリしたデータに統合する作業です。

② 微分: V'(x) = 12x² - 276x + 1080

【AI戦術シミュレーター起動】 今の攻撃力ではなく、「戦術（x）をあと1歩変えたら、攻撃力がプラスに動くか？マイナスに動くか？」という、近未来の変化の勢いを弾き出すソフトを走らせた状態です。

③ 12でくくる: 12(x² - 23x + 90)

【共通要因の整理】 全員のコンディションや天候など、全体にかかるベースの数字（12）を一旦外へ置いて、純粋な「フォーメーションの相性（カッコの中身）」だけに焦点を絞り込んで分析しやすくします。

④ 因数分解: 12(x - 5)(x - 18) = 0

...【2人のキーマン特定】 複雑なデータパズルから、「戦術的に大きな変化（ゼロ）を生み出す、運命の数字は 5 と 18 だ！」と、重要なピンポイントの選択肢をスカウティングで導き出した瞬間です。

⑤ 答えの決定: x = 18 は不適、よって x = 5

【非現実プランの却下とスタメン発表】 候補の「18」はピッチの外にはみ出てしまうルール違反（定義域外）なので即却下。ルール内で最強になれる「選手間 5 メートルの陣形（x = 5）」を本日のスタメンに決定します！
