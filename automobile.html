🔧 1. ボンネットを開けてできる応急処置

① バッテリー上がり → セル回らず 定番

ブースターケーブルがなければ、手動車（MT）なら押しがけ。ATは不可。

手順：

  • イグニッションON（エンジンは掛けない）
  • 2速に入れてクラッチを踏む
  • 誰かに押してもらい、時速10km/h程度でクラッチを繋ぐ
  • エンジンが掛かったらすぐクラッチを踏む
⚠️ 最近の車は電子制御が多いので、押しがけでECUが壊れる可能性アリ。最終手段。

② オルタネーター故障 → 走行中に電気が尽きる

オルタが死ぬとバッテリーだけで走ることになる。ヘッドライト・エアコン・オーディオ全部OFF。昼間なら30〜60分は走れる。

メーターのバッテリーマークが点灯したら即座に電気を節約。夜ならライトだけは消せないので最寄りの整備工場へ直行。

③ ラジエーターホース破裂 → 冷却水漏れ 緊急

走行中に水温計がレッドゾーン → ボンネットから白煙。これはエンジンブロー寸前。

応急処置：

  • すぐ安全な場所に停車、エンジンOFF
  • ボンネットを開けて冷えるまで待つ（30分以上）
  • ラジエーターキャップは絶対に熱い状態で開けない（熱湯噴射で大火傷）
  • 応急なら水道水をラジエーターに補充して最寄りまで
  • ガムテープ＋布でホースの裂け目を応急補修も可
💡 冬場は水道水だと凍結するので、できればLLC（クーラント）を。

④ ファンベルト切れ → パワステ・オルタ・ウォーターポンプ停止

走行中に「キーッ」と異音 → ハンドルが重くなる → バッテリーランプ点灯。これがファンベルト切れのサイン。

応急：ストッキング（女性のタイツ）をベルト代わりに巻くという昔ながらの裏技。最近の車は細いので厳しいが、非常時には使える。

⑤ サーモスタット固着 → オーバーヒート

サーモが閉じたままだと冷却水が循環せず、すぐオーバーヒート。逆に開きっぱなしだと冬場に暖房が効かない。

応急：サーモスタットを外してガスケット代わりに段ボールを挟んで組む、という荒技もあるが、基本は交換。

⑥ ヒューズ切れ → 電装品死亡

ボンネット内のヒューズボックスを開け、切れているヒューズを確認。同じアンペア数の予備ヒューズと交換。

予備がなければ、同じアンペアの別系統ヒューズを一時的に借りる（例：ラジオのヒューズをヘッドライトに）。ただし早急に正規品と交換。

⑦ スターターモーター故障 → セルが回らない

ボンネットを開け、スターターをハンマーでコンコンと叩く。ブラシが固着している場合、これで復活することがある。

叩く場所：スターター本体（バッテリーの太いケーブルが繋がっている円筒形のやつ）。

🛠️ 2. ボンネット以外の応急テクニック

① タイヤバースト → スペアタイヤなし

パンク修理キットがない場合、パンク穴にネジをねじ込むという荒技。ただしチューブレスタイヤ限定。

もっと安全なのはパンク修理剤（スライム）をバルブから注入。ただしTPMS（空気圧センサー）が壊れる可能性アリ。

② キー閉じ込み → スマートキーなし

昔の車なら針金ハンガーでドアロックを引っ掛ける。窓の隙間から差し込んでロックノブを引っ張る。

最近の車はデッドロック機能があるので無理。JAFを呼ぶのが賢明。

③ ガス欠 → スタンドまでたどり着けない

実はタンク内に数リットルの予備が残っていることが多い。車を揺らしてガソリンを集め、傾斜地でエンジンを掛けると数km走れることも。

ただしインジェクション車は燃料ポンプが空になると焼き付くので注意。

④ ヘッドライト球切れ → 夜間走行

予備球がなければ、ハイビームとロービームの球を入れ替える。多くの車は同じH4球を使っているので、片方生きていれば交換可能。

またはフォグランプで代用。片側だけでも走行は可能。

⑤ ワイパー故障 → 雨天走行

ワイパーが動かない場合、じゃがいもをワイパー代わりに使うという昔の裏技。じゃがいもに含まれるサポニンが撥水効果を発揮する。

もっと現実的には撥水スプレーをフロントガラスに塗布。時速60km/h以上なら雨滴が飛んでいく。

⑥ AT車のシフトロック解除

ブレーキを踏んでもPから動かない時、シフトロック解除ボタン（シフトノブ付近の小さな穴）をマイナスドライバーで押すと動かせる。

これはバッテリー上がりやブレーキスイッチ故障時の必須テク。

⑦ 電子スロットル故障 → アイドリング不安定

スロットルボディが汚れているとアイドリングが不安定に。エアクリーナーを外してスロットルをパーツクリーナーで拭くだけで改善することも。

🤫 3. 車屋さんが黙って使う秘密テクニック

① OBD2スキャナーでエラーコード消去 必須

最近の車はOBD2ポート（運転席下）にスキャナーを挿すと、エラーコードが読める。Amazonで3000円〜。

コード例：

  • P0300 → 失火
  • P0420 → 触媒効率低下
  • P0171 → 混合気リーン
  • P0128 → サーモスタット異常

消去して再発しなければ、一時的なエラーだった可能性大。

② バッテリー交換後の再学習

バッテリーを外すとECUがリセットされ、アイドリングが不安定になる。これを再学習という。

手順（多くの車種共通）：

  • エンジン冷間時に掛ける
  • エアコン・ライト全部OFF
  • 10分間アイドリング
  • アクセルをゆっくり3000回転まで上げて戻す × 3回

③ オイル漏れ → シーリング剤で応急

オイルパンから漏れている場合、オイルストップ（シーリング剤）を入れるとゴムパッキンが膨張して止まることがある。

ただし一時しのぎ。早めにガスケット交換を。

④ エアコンガス補充の裏技

エアコンが効かない時、自分でガス補充キット（3000円程度）を使える。低圧側ポートに繋いでゲージを見ながら補充。

ただし高圧側に繋ぐと爆発するので絶対に間違えないこと。

⑤ ブレーキフルード漏れ → 応急

ブレーキがスカスカになったら、ブレーキフルードを補充。DOT3 or DOT4を指定通りに。水で代用は絶対ダメ。

漏れ箇所がわかっているなら、パイプをペンチで潰して応急処置という荒技も（緊急時のみ）。

⑥ マフラー穴あき → 応急

走行中に「ボボボ」と爆音。マフラーに穴が開いている。応急ならガムテープ＋アルミホイルで塞ぐ。ただし熱で溶けるので短距離のみ。

⑦ ウォーターポンプ故障の予兆

走行中に「シャラシャラ」という異音＋冷却水漏れ → ウォーターポンプのベアリング破損。

応急：冷却水を補充しながら最寄りまで。ただし放置するとオーバーヒートでエンジンブロー。

⑧ 燃料ポンプ故障 → 叩いて復活

ガソリンタンク内の燃料ポンプが死んだ時、タンクの底をハンマーでコンコンと叩くと復活することがある。ブラシが固着している場合のみ。

⑨ イモビライザー解除不能 → 鍵屋呼ぶ前に

スマートキーの電池切れでエンジンが掛からない時、スマートキーをスタートボタンに直接押し当てると、電波でなく電磁誘導で認識される。

これは知らない人が多い裏技。

⑩ セルモーター回らず → AT車の非常手段

AT車でセルが死んだ場合、スターターリレーを直接ショートさせる方法がある。ただし感電・火災の危険大。プロのみ。

安全なのはJAFを呼ぶこと。

🧠 4. プロの診断テクニック（見た目・音・匂いで判断）

① 音で判断

  • カチカチ → バッテリー上がり or スターター
  • キーッ → ファンベルト
  • シャラシャラ → ウォーターポンプ or チェーン
  • ゴゴゴ → エンジンマウント
  • ヒューン → タービン or ベルト

② 匂いで判断

  • 甘い匂い → クーラント漏れ
  • 焦げた匂い → オイル漏れ or クラッチ
  • ガソリン臭 → 燃料漏れ（危険）
  • 卵の腐った匂い → 触媒劣化

③ 色で判断（オイル・ATF・クーラント）

  • エンジンオイル：琥珀色 → 正常、黒 → 交換時期、白濁 → ヘッドガスケット抜け
  • ATF：赤 → 正常、茶色 → 交換、黒 → 焼け
  • クーラント：緑/赤 → 正常、茶色 → 錆

④ タイヤの摩耗でアライメント診断

  • 内側だけ減る → キャンバー狂い
  • 外側だけ減る → トーイン過多
  • 中央だけ減る → 空気圧過多
  • 両端だけ減る → 空気圧不足

🚨 5. 故障時の優先順位（これだけ覚えろ）

  1. 安全確保：ハザード → 路肩 → 三角表示板
  2. エンジンOFF：異音・煙・水温レッドなら即OFF
  3. 状況判断：音・匂い・メーターで原因を絞る
  4. 応急処置：上記のテクを試す
  5. JAF/保険会社：無理なら呼ぶ（JAFはロードサービス付き保険で無料）
💡 JAF会員なら年間4000円程度で何度でも無料ロードサービス。保険のロードサービスと重複加入すると安心。

📊 6. 覚えておきたい数字

  • バッテリー電圧：12.6V（正常）、12.0V以下で要充電
  • オイル交換：5000〜10000km or 6ヶ月
  • タイヤ空気圧：2.2〜2.5kg/cm²（車種による）
  • ブレーキパッド残量：3mm以下で交換
  • クーラント交換：2年 or 4万km
  • ATF交換：4〜6万km
  • タイミングベルト：10万km（チェーンは基本交換不要）
